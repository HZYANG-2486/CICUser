# CICUser

把 ClassIsland 的**当前课堂状态**与**当日课表**实时上报到自建服务端，供走廊大屏、电子班牌、教务看板等场景展示。

## 插件作用

ClassIsland 的课表与课堂状态只存在于教室电脑本地。本插件把这些信息定时推送到一台服务器上，于是：

* 走廊大屏能显示「高一(1)班正在上数学，还剩 12 分钟」；
* 电子班牌能展示当天班级课表；
* 教务看板能汇总多个班级的实时上课情况。

数据只发往你配置的地址，不经过任何第三方中转。

## 特性

| 特性                      | 说明                                                       |
| ------------------------- | ---------------------------------------------------------- |
| **状态实时上报**    | 当前科目、时段、课堂状态、下一科目与剩余时间               |
| **课表自动上报**    | 启动时上报当日完整课表，并带版本号                         |
| **换课即时同步**    | 监听课表变更，3 秒内防抖合并并立即重传最新版本             |
| **三通道独立上报**  | 状态 / 课表 / 心跳三条链路各自独立开关与间隔               |
| **课表格式自定义**  | 4 种报文预设 + 字段级自定义，适配不同服务端解析习惯        |
| **报文模板管理**    | 字段级增删改，多套模板可另存、切换、删除                   |
| **多套配置**        | 按教室保存多套连接配置，一键切换；支持导入导出分发         |
| **设备ID 自动生成** | 首次运行自动生成唯一标识，支持 5 种生成方式                |
| **自动化触发**      | 提供行动，可在自动化流程中手动触发上报                     |
| **撤回与恢复默认**  | 多步撤销栈（上限 20 步）+ 一键恢复出厂默认                 |
| **安全加固**        | 输入校验、日志脱敏、请求超时、指数退避重试、明文 HTTP 拦截 |

## 安装

1. 打开 ClassIsland → 应用设置 → 插件
2. 从本地文件安装 `CICUser.cipx`
3. 重启宿主后，左侧导航出现「CICUser」分组
